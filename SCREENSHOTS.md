# Screenshot capture plan

Save screenshots in this folder. Use descriptive names and capture the actual running project after testing.

1. `01-desktop-homepage.png` — Full desktop page top showing announcement, header, navigation, hero, and benefits.
2. `02-category-section.png` — All category tiles and the beginning of the product grid.
3. `03-product-grid.png` — At least 12 product cards visible across the product section; use a full-page screenshot if needed.
4. `04-search-filter.png` — Search query or selected category with filtered results.
5. `05-sort-results.png` — Product sorting menu/results (optional but useful evidence).
6. `06-cart-open.png` — Cart drawer showing item count, quantity controls, and subtotal.
7. `07-mobile-view.png` — Browser responsive mode at about 390px wide showing mobile header, hero, and two-column products.
8. `08-mobile-menu.png` — Mobile navigation expanded.

## How to capture
- Windows: `Win + Shift + S`, or Chrome DevTools → device toolbar.
- For a full-page screenshot: Chrome DevTools → Command Menu (`Ctrl + Shift + P`) → “Capture full size screenshot”.
- Avoid including personal notifications, account details, or unrelated desktop content.
- Do not fabricate screenshots. Capture the actual website after running it.
