## 1. Abstract
ShopNova is a responsive e-commerce homepage developed using HTML5, CSS3, and vanilla JavaScript. The project studies common shopping website patterns and recreates a similar browsing experience using original branding, sample products, promotional messaging, and independently written code.

## 2. Objectives
- Build a structured online-shopping homepage.
- Use semantic HTML and organized CSS.
- Apply Flexbox, CSS Grid, and media queries for responsive layouts.
- Implement search, category filtering, sorting, banner controls, navigation interactions, and cart management.
- Practice testing and publishing a static frontend project.

## 5. Main Modules
### Header and navigation
Contains ShopNova branding, delivery information, search controls, language/account/order buttons, cart count, and responsive category navigation.

### Hero slider
Shows three original promotional messages and supports previous/next slide controls.

### Category browsing
Provides category tiles for Electronics, Fashion, Home & Kitchen, Beauty, Mobiles, Books, and Sports.

### Product catalogue
Displays 12 sample products with image, name, category, rating, review count, current price, original price, discount, and Add to Cart control.

### Search, filters, and sorting
Users can search by product name/category/description, filter by category, view deals, and sort by price, rating, or discount.

### Shopping cart
Supports adding products, quantity changes, item removal, live item count, subtotal, and a demo checkout message. No real payment is taken.

### Footer and responsive design
Provides grouped navigation links and layout changes for desktop, tablet, and mobile screens.

## 6. Implementation Approach
The interface is structured in semantic HTML. CSS variables define a consistent palette and typography, while Grid and Flexbox manage component layout. Media queries adapt the header, navigation, category grid, product grid, and footer to smaller screens. JavaScript stores sample product data in an array, renders product cards, and updates the visible products and cart when the user interacts with the controls.
